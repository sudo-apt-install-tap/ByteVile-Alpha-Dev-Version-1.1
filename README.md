# BYTEVILE ALPHA DEV VERSION 1.1
*"The code remembers. Even when you don’t."*

---

## About
ByteVile is a terminal-based narrative experiment — a text adventure set inside a decaying digital world.  
This version is in **active development**. Expect bugs, unfinished features, and strange artifacts.

---

## Commands
start - begin the story
save - save progress
load - load previous save
exit - quit the game
